# kintone-command-palette

English version: [README.md](./README.md)

kintoneのアプリ画面で Ctrl+K（macOSでは Cmd+K）を押すと検索ボックスが開き、アプリ・一覧・レコード・アクションを入力に合わせて絞り込み、Enterで選択先に移動する。LinearやVS Codeのコマンドパレットと同じ操作感。kintoneでアプリ間を移動するには通常ポータルへ戻るかブラウザのブックマークを使うしかなく、一覧の切り替えもマウスでドロップダウンを開く必要がある。このプラグインを入れると、こうした移動をキーボードから手を離さずに済ませられる。外部サーバーへの送信はなく、処理はすべてブラウザ内とkintone REST APIで完結する。

## 機能

- プラグインを追加したアプリの一覧・レコード詳細・作成・編集の各画面で開ける。
- 検索対象は4種類。閲覧できるアプリ、現在のアプリの一覧、現在のアプリのレコード、固定のアクション（レコード作成、アプリ設定を開く、絞り込み解除、一覧に戻る）。
- アプリ名・一覧名・アクション名は、全角半角とカタカナ・ひらがなを正規化するあいまい一致で検索する。`kintone` で `Ｋｉｎｔｏｎｅ` が、`かたかな` で `カタカナ` がヒットする。
- レコードは、設定で選んだ最大3つのテキストフィールドに対する `like` クエリで検索する。
- 検索語が空のときは最近使った項目を表示する。よく使う移動先には1キーで届く。
- 矢印キーで選択を移動、Enterで実行、Tabで検索対象の切り替え、Escで閉じる。日本語IMEの変換中は、確定のEnterや取り消しのEscでパレットが実行されたり閉じたりしない。

## 制限事項

- パレットが動くのは、プラグインを入れたアプリの中だけ。kintoneのプラグインはポータルやスペースでは動かせないため、全アプリ横断のランチャーにはならない。これはkintoneプラットフォームの制約で、設定では変えられない。
- レコード検索はkintoneの `like` 演算子を使う。英数字は単語単位の一致になるため、`abc` で `abcdef` の途中は検索できない。日本語にはこの制限はない。
- モバイルは非対応。ショートカットと矢印キー操作は物理キーボードが前提で、ソフトウェアキーボードでは成立しない。モバイル用バンドルは同梱していない。
- Firefoxでは Ctrl+Shift+K がページより先に開発者ツールを開いてしまう。Firefoxでは既定の Ctrl+K のまま使うこと。

## インストール

1. プラグインのzipをビルドする。
   ```
   npm install
   npm run build
   npm run pack
   ```
   `npm run pack` が `dist/plugin.zip` を出力する。初回実行時にはプロジェクトルートに `private.ppk` も生成される（git管理外）。以降のビルドでも同じ `private.ppk` を使い回せば、プラグインIDが変わらない。
2. kintoneでアプリの設定を開き、「プラグイン」から `dist/plugin.zip` を追加して、アプリにプラグインを追加する。
3. アプリを更新して反映する。

## 設定

- ショートカットキー: Ctrl+K（既定）、Ctrl+Shift+K、無効のいずれか。無効にするとキーリスナー自体を登録しない。
- 検索対象の切り替え: アプリ検索・一覧切り替え・レコード検索・アクションを個別にオンオフできる。無効にした対象は検索結果・Tabでの切り替え・RESTリクエストのいずれからも外れる。
- レコード検索フィールド: 検索対象を最大3つ選ぶ。一覧に出るのは文字列（1行）・文字列（複数行）・リンクの各フィールドのみ。レコード検索を有効にする場合は1つ以上必須。同じフィールドの重複指定は保存時に弾く。フィールドはフィールドコードで保持するため、フィールド名を変えても設定は有効なまま。フィールドの削除や型変更があった場合は、再選択が必要な状態になる。

## データとプライバシー

外部サーバーには何も送らない。使うのはブラウザのストレージ2箇所。

- `sessionStorage` の `kp-cmdp-apps-<domain>-<userCode>` に、アプリ一覧を10分間キャッシュする。開くたびの再取得を避けるため。消したいときはタブを閉じるか、ブラウザの開発者ツールからキーを削除する。
- `localStorage` の `kp-cmdp-recent-<domain>-<appId>-<userCode>` に、アプリ・ユーザーごとに最近使った項目を最大20件保持する。履歴を消すには開発者ツール（Application > Local Storage）でこのキーを削除する。

プライベートモードや容量超過でストレージが使えない場合は、履歴とキャッシュだけが止まり、パレット本体はそのまま動く。

## 開発

```
npm install
npm run typecheck   # tsc --noEmit
npm test            # vitest, core logic
npm run build       # dist/desktop.js and dist/config.js
npm run pack        # dist/plugin.zip
npm run lint        # eslint
```

kintoneに依存しないロジック（あいまい一致、likeクエリ、履歴、フィルタ状態、設定スキーマ、キャッシュTTL）は `src/core` にあり、単体テストの対象。`src/kintone` にREST呼び出しとURL組み立てを分離し、`src/desktop` がパレットのDOMを組む。`test/e2e` のE2E仕様は主要フローを記述したもので、環境変数で接続先を指定した開発環境に対して実行する。
